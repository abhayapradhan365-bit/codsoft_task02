Python Calculator 🧮

About the Project

The Calculator is a simple command-line application developed using Python as part of the CodSoft Python Programming Internship.

It allows users to perform basic arithmetic calculations through a menu-driven interface.

Features

- Addition: Adds two numbers.
- Subtraction: Subtracts one number from another.
- Multiplication: Multiplies two numbers.
- Division: Divides one number by another.
- Division-by-Zero Handling: Displays an error message when division by zero is attempted.
- Multiple Calculations: Allows users to perform calculations repeatedly.
- Input Validation: Handles invalid inputs and menu choices.

Technologies Used

- Python 3
- Visual Studio Code

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

python calculator.py

How to Use

1. Run the program.
2. Enter two numbers when prompted.
3. Select the desired operation:
   - "1" — Addition (+)
   - "2" — Subtraction (-)
   - "3" — Multiplication (*)
   - "4" — Division (/)
   - "5" — Exit
4. Follow the instructions displayed in the terminal.

Example

Enter first number: 10
Enter second number: 5

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit

Enter your choice (1-5): 1
Result: 15.0
